# 找图出处 · Find Image Source

看到一张图想知道它从哪来:右键一下,侧边栏并排给出五家引擎的结果。

## 它能做什么

- 网页上的图片、B 站视频里的某一帧,都能搜
- 五家引擎同时跑:**Google Lens、Yandex、ascii2d、SauceNAO、TraceMoe**
- 结果并排列在侧边栏,点一条直接跳到出处,也能一键复制本次结果摘要
- 取图有三层兜底:页面 canvas → 后台 fetch → 截屏裁剪,防盗链的图也拿得到

## 安装

1. 在本页点绿色 **Code → Download ZIP**,解压到任意文件夹(比如 D:\找图出处)。
2. Edge 地址栏打开 edge://extensions,打开左下角「开发人员模式」。
3. 点「加载解压缩的扩展」,选解压出来、里面直接能看到 manifest.json 的那一层文件夹。
4. 装好后按 Ctrl+Shift+Y,或者右键任意图片选「用这张图找出处」。

> Chrome 不知道能不能，可以试试

## 用法

- **右键图片** →「用这张图找出处」
- **快捷键** Ctrl+Shift+Y:搜当前标签页里的图或视频帧
- **工具栏图标**:右键图标也有同名入口

SauceNAO 想走 JSON 接口的话,在侧栏设置里填自己的 API Key,免费账号每天约 100 次;不填就走匿名 HTML 搜索,能出结果但额度低。

## 说明

- 所有请求都由你自己的浏览器直接发出,不经过任何中间服务器,没有统计和上报。
- Google、Yandex 这两家要能正常访问,建议开代理。
- 扩展只在你主动触发时工作,不会自己在后台跑。
