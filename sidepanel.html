找图出处

右键任意图片 →「用这张图找出处」

还没有图片

在任意网页的图片上点右键，选「用这张图找出处」；视频上点右键可以搜「当前这一帧」。

播放器自己接管了右键（B 站、YouTube 等）时，用 Ctrl+Shift+Y、 右键工具栏图标、或者右上角「抓帧」，抓当前正在播的那一帧。 （Ctrl+L 这类浏览器自带键、以及 Ctrl+Alt 组合都会被浏览器/系统先吃掉，别设成那些）

也可以点右上角「本地图」选文件，或者把图片直接拖进来、Ctrl+V 粘贴截图。

搜不到先看这里：截图尽量带完整一格（对白框、边框、背景都在），别只抠脸； 分辨率别太小；黑白漫画优先看 ascii2d 的「特徴」。

侧边栏太窄时可以把边缘往左拖宽，或在右上角点「宽屏」。

相似度门槛（SauceNAO）

默认关。关着时 SauceNAO 会把 50～79% 的候选也列出来——裁剪过的本子图大多落在这一档，低分标灰。

🔑 SauceNAO API Key（点这里填写）

不填也能用：会走匿名的 HTML 模式（官网不登录也能搜）。填了就走 JSON API，字段更全、少解析风险、额度更高。 Key 在 SauceNAO 的 API 页 （注意不是「账号」页；账号页只显示 api access: enabled）。免费账号就有。

图片只发给对应引擎，本扩展不收集、不上传任何数据。
