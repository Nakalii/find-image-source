本插件是「未打包的浏览器扩展」，安装方式与普通软件不同，不需要双击运行。

一、安装（Edge）
1. 把 find-image-source-0.13.0.zip 解压到一个**以后不要删**的文件夹，例如 D:\find-image-source
   （扩展直接从这个文件夹运行，删掉它就失效）
2. 打开 Edge，地址栏输入：edge://extensions/
3. 打开左下角（或左侧栏）的「开发人员模式」
4. 点「加载解压缩的扩展」，选择第 1 步解压出来的那个文件夹
   （注意：选文件夹本身，不要选里面的某个文件）
5. 安装完成后，点浏览器右上角的拼图图标，把「找图出处」固定到工具栏

二、使用
- 在网页图片上右键 →「用这张图找出处」
- 页面背景图 / canvas：右键页面空白处 →「用页面上的图找出处（背景图 / canvas）」，再点一下要搜的图
- 视频：右键视频 →「用这张视频的当前帧找出处」，或按 Ctrl+Shift+Y
- 侧边栏右上角「⚙ 设置」里可以填 SauceNAO 的 API Key

三、注意事项
1. 有的引擎要挂代理才通（Google Lens、Yandex、ascii2d 视网络情况而定），
   某列显示「需要代理」时先检查代理是否开着。
2. SauceNAO 需要自己填 API Key（免费账号就有）：
   拿 Key 的页面是 https://saucenao.com/user.php?page=search-api
   不填也能搜，但走匿名模式、额度低，且可能被拦。
3. 每次更新扩展文件后，要在 edge://extensions/ 里点这个扩展的「重新加载」才生效，
   并刷新已经打开的网页（否则页面里残留旧脚本）。
4. 扩展不会把图片存到磁盘：截屏/下载的图片只在内存里用完即弃，
   设置页可以看到「本地缓存占用」，只有 Key 和开关会占一点空间。

版本：0.13.0
